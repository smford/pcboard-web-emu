PCBoard BBS & MS-DOS Terminal Emulator

Overview

This web application is a high-fidelity emulator of an IBM PC compatible running MS-DOS 6.22 and dialing into a Clark Development Company PCBoard v15.22 Multi-Node Bulletin Board System (BBS).

Getting Started & Dialing

  • Click 📞 Connect BBS in the toolbar to dial immediately with synthesized modem audio.
  • Or from the MS-DOS prompt C:\>, type PCBOARD or BBS.
  • Or type TELIX to enter the modem terminal and type ATDT 555-1994.

PCBoard BBS Login Accounts

  • SysOp Access: Log in as First Name: Fred, Last Name: Clark (or SysOp SysOp) to unlock Security Level 110!
  • Returning Caller: First Name: Guest, Last Name: Caller (or John Doe).
  • New User Registration: Enter any custom first and last name to experience the authentic new user intake questionnaire!

PCBoard Main Menu Features

  • [M] / [R] - Message Base: Read threads and post new messages (saved locally).
  • [F] / [D] - File Directories: Browse DOS shareware and simulate ZMODEM transfers.
  • [B] - System Bulletins: View hardware specs, rules, and SRE uptime metrics.
  • [W] - Who's Online: View multi-node caller activity.
  • [C] / [O] - Chat with SysOp: Page the SysOp console with authentic PC speaker chimes!
  • [L] - Legend of the Red Dragon (L.O.R.D.): Play the classic BBS tavern door game!
  • [T] - TradeWars 2002: Space trading and sector navigation.
  • [G] or [DOS] - Goodbye: Log off with session statistics and return to MS-DOS.

MS-DOS 6.22 Commands

Supported commands at the C:\> prompt: DIR, CD, TYPE, MEM, VER, DATE, TIME, BEEP, CLS, HELP, TELIX, PCBOARD.

SRE Infrastructure & Reliability

Built as a zero-dependency progressive web app designed for 100% offline availability on GitHub Pages. Sound effects (modem handshake, PC speaker, Model M key clicks) are synthesized via Web Audio API oscillators and noise generators.
